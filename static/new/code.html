My Notes

Morning Session

Architecture Talk

  • Layered architecture leads to tight coupling over time
  • Ports and adapters keep the domain pure
  • Don't let frameworks bleed into business logic

Refactoring Exercise

  • Extract method before extract class
  • Name reveals intent, not implementation
  • Small steps, always green tests

Afternoon Session

Testing Strategy

  • Unit tests for domain logic, integration tests for adapters
  • Avoid testing implementation details
  • Test pyramid: many unit, fewer integration, few E2E
  • Mutation testing reveals gaps in coverage

Code Smells Identified

  • Long parameter lists → introduce parameter objects
  • Feature envy → move method closer to data
  • Primitive obsession → wrap with value objects
  • Data clumps → extract into cohesive classes
