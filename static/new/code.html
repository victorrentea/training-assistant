Session Summary

Key Concepts Covered

Architecture Principles

  • Single Responsibility and separation of concerns
  • Dependency inversion keeps modules decoupled
  • Hexagonal architecture isolates domain logic from infrastructure
  • Ports and adapters enable testability

Design Patterns

  • Repository pattern abstracts persistence
  • Command/Query separation improves clarity
  • Factory methods encapsulate object creation
  • Observer pattern drives reactive pipelines

Discussion Highlights

Open Questions from Participants

  • When does eventual consistency outweigh strong consistency?
  • How do you migrate a monolith incrementally without downtime?
  • Is clean architecture overkill for small services?
  • How do you enforce architecture rules in CI?

Takeaways by Vote

  • 12 participants flagged Hexagonal Architecture as most valuable
  • 8 participants want a deeper dive on Event Sourcing
  • TDD resonated most with junior developers in the room
